# Nice Gadgets Store
A responsive e-commerce web application for browsing and shopping for electronic devices, including smartphones, tablets, and accessories.

## Team Project

The application was developed in a team of five developers. We collaborated on building the application, integrating features, and maintaining a consistent user interface across the project.

Original team repository: [FiveEnds / Frontend](https://github.com/FiveEnds/Frontend)

## Features
- Product Catalog — browse products and explore product cards.
- Filtering & Sorting — find products using available filters and sorting options.
- Pagination — navigate through the catalog and load more products.
- Shopping Cart — add and manage products in your cart.
- Favourites — save products for later.
- Responsive Design — optimized for different screen sizes.
- Dark Mode — switch between light and dark themes.
- Navigation — page navigation with breadcrumbs and reusable layout components.

## Technologies

- Frontend: React, TypeScript, Tailwind CSS
- State Management: Zustand
- Routing: React Router
- Animations: Motion, Canvas Confetti
- Build Tool: Vite

## Getting Started

Prerequisites

- Node.js
- npm

## Installation

Clone the repository:
```
git clone https://github.com/vlad4uikov/nice-gadgets-store.git
```

Install dependencies:
```
npm install
```
Start the development server:
```
npm run dev
```
Build

To create a production build:
```
npm run build
```
